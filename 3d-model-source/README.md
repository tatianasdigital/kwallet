# Kampela — исходник 3D-модели

Модель строится процедурно в Three.js (`src/kampela-model.js`). Это единый источник правды:
из него экспортируется `kampela.glb` для сайта, а из GLB собирается редактируемый `blender/kampela.blend`.

## Структура

| Путь | Что это |
|---|---|
| `src/kampela-model.js` | Геометрия, материалы, текстуры (canvas) — все размеры в мм в объекте `DIM` |
| `src/kampela-viewer.js` | Тот же вьюер, что и на сайте |
| `dev/index.html` | Живой просмотр процедурной модели (без экспорта) |
| `tools/render.mjs` | `node tools/render.mjs export` → `public/models/kampela.glb`; `node tools/render.mjs shots` → кадры турнтейбла в `out/` |
| `tools/glb_to_blend.py` | GLB → `blender/kampela.blend` (турнтейбл 300 кадров, камера, свет, акрил под Cycles) |
| `blender/kampela.blend` | Редактируемый файл Blender 5.2 |
| `public/models/kampela.glb` | Готовая модель |

## Как пересобрать

```bash
npm install                       # three, three-bvh-csg, three-mesh-bvh
npx playwright install chromium   # один раз, если Playwright ещё не стоит
node tools/render.mjs export      # новый GLB
python tools/glb_to_blend.py      # новый .blend (нужен Blender как модуль: pip install bpy, либо blender -b -P tools/glb_to_blend.py)
```
Живой просмотр: `python -m http.server 8765` в этой папке → `http://localhost:8765/dev/index.html`
(параметры: `?bg=%23e6e6e4&tilt=0&speed=0&angle=3.14&card=0`).
Готовый GLB скопируй в `../public/models/kampela.glb`.

## Устройство модели

* Корпус: один цельный объём прозрачного акрила 112 × 44 × 7 мм, R углов 5,5 мм, фаска 0,7 мм.
  Спереди над окном NFC вырезано углубление 27 × 27 × 1 мм, сзади — лоток 31 × 31 × 0,8 мм (булевы операции).
  Материал: transmission = 1, IOR 1,49 (PMMA), лёгкий зелёный оттенок толщи, как у литого акрила.
  Тонкие матовые линии по периметру изображают стыки слоёв ламинированного корпуса.
* Внутри: кольцо NFC-катушки (зелёная плата, белые витки), съёмная карта-антенна в окне,
  основная плата 39 × 66,5 мм, e-ink 52 × 37 мм с экраном seed phrase, оранжевые шлейфы с перегибом через край платы,
  батарея конденсаторов (блок 7 × 4 + колонка 2 × 5), микросхемы, ZIF-разъём, ~100 мелких SMD-компонентов,
  ряд золотых контактов под экраном, белые проставки, чёрная лента на торце.
* Pivot — геометрический центр. Ось Y — длинная ось устройства, +Z — сторона экрана.
* Геометрия объединена по материалам: 32 меша, ~16 тыс. треугольников.

## Допущения (то, чего не видно на референсах)

1. **Точные размеры.** Чертежей нет. Пропорции сняты с фото (длина ≈ 2,5 ширины), абсолютные
   112 × 44 × 7 мм — оценка по фото в руке рядом с телефоном и по толщине торца.
2. **Внутренние слои корпуса.** На фото видна слоистость торца, но не толщина каждого слоя.
   Корпус сделан одним объёмом, стыки показаны линиями.
3. **Обе стороны карты-антенны.** На одних фото в окне зелёная карта со спиралью, на главном фото
   (Figma `device-image`) со стороны платы — серебристая сетка. Принято: лицевая сторона зелёная, обратная — экранирующая сетка в тёмной рамке.
   Карту можно скрыть (узел `Antenna_Card`).
4. **Шелкография и мелкие компоненты** — правдоподобная раскладка, не копия трассировки платы:
   повторены крупные узнаваемые элементы (логотип-камбала, `https://kampela.io`, «Alzymologist», 2023),
   расположение крупных микросхем, шлейфов, разъёма и конденсаторов.
5. **Сторона экрана под e-ink** не видна — там плата без деталей.
6. **Короткие торцы.** Портов и кнопок на референсах нет, поэтому не добавлялись.
   Чёрный узел на нижнем торце со стороны платы повторён по фото.
7. **Наклон 25°** в hero взят с постера `device-hero.png`; модель вращается вокруг собственной длинной оси.
